# 自定义指标使用受控可视化表达式树

MVP 不允许输入公式文本，只允许通过可视化构建器创建指标：基础聚合限定为 `SUM`、`AVG`、`MIN`、`MAX`、`COUNT_ROWS`、`COUNT_VALID` 和 `COUNT_DISTINCT`，每个基础指标可附加受控筛选，派生指标只能用指标、数值常量、括号和 `+ - × ÷` 组合，并提供内置环比、同比与目标差异。加减要求单位和币种兼容，乘除推导比例或复合单位；缺失值按既定规则排除并显示缺失率，除零返回带原因的“不可用”，绝不伪装为零或无穷大。AI 可以提议构建树，但所有者必须确认聚合、筛选、单位与口径；行级计算列、窗口函数、条件表达式、文本公式、跨数据集计算和任意 SQL 均不进入 MVP。该边界牺牲部分高级分析表达力，以换取指标可解释、可验证、可迁移且能安全编译为确定性分析计划。
