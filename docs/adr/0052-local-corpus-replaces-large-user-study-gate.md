# 本地自动化闭环语料库取代大规模用户测试门槛

MVP 不再以 50 名用户中 60% 在十分钟内完成作为发布门槛，因为项目现阶段无法获得该规模样本；“10 分钟可分享成果率”保留为尚未验证的产品假设，不得对外宣称已经达成。M4 改为强制运行完全本地的自动化闭环语料库：至少 30 份带确切预期的人工黄金表格、200 份确定性生成的有效表格、100 份格式错误或资源攻击等无效表格，以及 1,000 组随机种子的指标性质测试；有效表格必须 100% 完成导入、生成、时间范围修改、联动重算和发布或导出并满足正确性与时延预算，无效表格必须 100% 明确拒绝且不得崩溃、挂起、抽样或转云端。AI 契约使用录制响应和模拟供应商验证；官方托管版本正式发布前再用维护方真实密钥执行供应商冒烟测试。该选择无法替代真实可用性研究，但提供项目当前能够持续、客观复现的兼容性、正确性、安全性和性能证据，并已同步写入 ADR-0043 与 ADR-0041。
