# 官方实例只允许严格限时的运行状态

DataPulse AI 不建设账号、项目、原始数据、故事内容或密钥数据库，但允许一个具有强制 TTL 的 Redis-compatible 临时 KV 层：官方实例使用阿里云 Tair，社区自托管参考使用 Valkey。该层只保存发布到期与撤销状态、发布管理凭证校验值、流量计数、限流键和工作量证明 nonce，不保存发布明文、分享密钥、分享密码、模型密钥或证据包；来源地址以每日轮换服务密钥生成的 HMAC 作为限流键，分享与限流状态最长保留 24 小时，匿名遥测进入独立的 30 天隐私指标管道。该决定修正 ADR-0034 的“完全无数据库”表述，以最小、可自动删除的运行状态换取原子撤销、配额和滥用控制，同时保持应用服务无状态和无长期用户内容数据库的承诺。
