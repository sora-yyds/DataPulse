# 测试与 CI 必须开源且可由 Fork 完整复现

DataPulse AI 使用 Vitest 验证分析算法、Schema、迁移器和后端逻辑，使用 React Testing Library 验证编辑器行为，使用 Storybook 维护故事区块状态样本，并由 Playwright 承担端到端、自动跨引擎近似、视觉回归与无障碍测试；GitHub Actions 在 PR 更新时提供快速反馈，在进入 merge queue 后对临时合并提交执行全部可复现强制矩阵并只允许通过者进入 `main`，主分支和正式发布再执行复核。仓库内的确定性质量门槛只使用合成数据且不得依赖付费专有 SaaS，任何 Fork 都能独立完整运行；官方托管版本发布还必须执行使用维护方密钥的真实供应商冒烟，以及真实 Safari 与微信设备检查，这些外部认证门槛的脚本和清单公开，但不作为 Fork 构建开源版本的必要条件。该边界保持源码正确性验证可复现，同时不把模拟接口或 Playwright 引擎误称为真实第三方服务与浏览器认证。
