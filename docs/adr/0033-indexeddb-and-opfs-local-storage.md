# IndexedDB 管理元数据，OPFS 保存加密大文件

创作端使用 IndexedDB 保存项目元数据、故事蓝图、版本索引、模型能力测试与不可导出设备密钥，使用 OPFS 保存加密数据集、Arrow 数据和大型资源，并在首次创建项目时请求持久存储权限；导入新版本或新增资源前同时检查浏览器配额与完整项目包 payload 上限，任何已提交项目都必须保持可完整流式备份。空间或备份上限不足时先阻止变更，允许项目所有者导出当前项目，再选择删除版本／资源或创建新项目，禁止自动清理或先形成无法完整备份的合法状态。该选择依赖创作端既定的现代 Chrome/Edge 范围，以更复杂的双存储事务、容量治理与迁移换取大文件能力、结构化索引和不使用 `localStorage` 保存数据或密钥的安全边界。
