# 生成模型只读取证据包，不读取原始数据集

完整数据集仅由确定性分析引擎处理，生成模型只接收列结构、字段角色、按外发规则裁剪的统计摘要、已计算的候选洞察与证据，以及每个获准分类字段最多 20 个且至少出现 5 次的高频标签；唯一标识、直接标识、所有者标记的机密字段、自由文本与稀有分类值不外发，调用前由项目所有者预览并可排除字段，所有指标计算仍由分析引擎执行。模型生成的每项数值陈述必须使用指标、证据或分析条件的有效引用，由渲染引擎填入实际值；硬编码额外数字、未知引用或口径不匹配均视为蓝图校验失败。该边界会减少模型直接理解特殊业务明细的机会，但能降低数据暴露、推理成本和数值幻觉，并使每条洞察可追溯复算。
