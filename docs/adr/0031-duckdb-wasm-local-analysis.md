# 本地分析使用 DuckDB-WASM、Arrow 与 ExcelJS

创作端在无运行时 import 的单文件模块 Web Worker 中使用 DuckDB-WASM 完成类型推断、筛选、聚合、排序、时间比较和交互数据包生成，以 Apache Arrow 在工作线程与界面之间传递列式数据；固定 WASM 资源在交付原始数据前由主线程预取、校验并传入，Worker CSP 不允许连接、网络脚本源或嵌套 Worker。ExcelJS 仅解析 `.xlsx` 工作表、显示格式和缓存公式结果，不执行公式或宏，CSV 则经流式解析与浏览器编码解码后进入同一分析层。该选择增加单文件构建、WASM 预加载、浏览器内存管理和 Worker 外传通道否定测试要求，但统一指标、图表、导出与发布聚合的计算语义，并避免手写多套分析实现或让原始数据处理依赖通过 `fetch`／动态 import 等通道外传原始数据。
