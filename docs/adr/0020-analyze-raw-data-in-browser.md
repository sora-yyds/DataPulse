# 原始数据集只在浏览器中分析

浏览器通过 File API 瞬时读取 Excel/CSV，并在隔离工作线程中完成解析、数据质量检查、分析处理、聚合与指标计算；原文件 Blob 不写入本地项目或云端，解析完成后释放引用，未被明确发布的原始数据行也不在设备性能不足时静默切换到云端。云端的数据内容输入只包括按外发规则裁剪的证据包、模型代理请求以及明确发布的内容；获准的无内容遥测和限时运行状态分别遵守 ADR-0041 与 ADR-0046，不改变原始数据本地分析边界。该选择以浏览器内存、兼容性与性能约束为代价，配合 ADR-0050 的多维导入准入条件，换取更低的云端成本与清晰的数据驻留边界。
