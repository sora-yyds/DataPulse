# 带密码分享不得在链接中暴露裸分享密钥

每次发布使用随机 256 位分享密钥和用途绑定的 AES-256-GCM 认证信封加密整个发布包：无密码分享可在版本化 URL Fragment 中携带分享密钥；带密码分享时，Fragment 只能携带由白名单 Argon2id profile 派生 KEK 所包裹的分享密钥、随机盐、包裹 nonce 和协议／profile ID，不得携带裸分享密钥或任意 KDF 参数，观看者在浏览器先校验长度、版本和 profile，再输入密码解包，密码、KEK 与分享密钥均不发送给服务器。项目包使用独立随机内容密钥和独立 purpose，不能复用分享材料；协议以固定互操作、错误、篡改和超限向量锁定编码与迁移语义。产品默认生成高熵密码，也允许至少 12 个字符的自定义口令并警告弱密码的离线猜测风险；撤销只能阻止后续下载，不能收回观看者已经下载、复制或截图的内容。该结构增加浏览器 WASM、版本注册表与多端互操作测试成本，但保证受保护明细要求的分享密码不是可被 URL 裸密钥或恶意 KDF 参数绕过的装饰性门槛。
