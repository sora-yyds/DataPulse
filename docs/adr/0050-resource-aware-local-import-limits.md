# 本地导入上限必须同时受设备与数据密度约束

MVP 的创作参考设备为 4 核 CPU、8 GB 内存、集成显卡并运行最新稳定版 Chrome 或 Edge；输入必须同时满足文件不超过 50 MB、行数不超过 200,000、列数不超过 100、非空单元格不超过 5,000,000，`.xlsx` 解压内容不超过 500 MB 且压缩比不超过 100:1，导入前估算峰值工作内存不得超过 1.5 GB。行数与列数上限分别在窄表和较短宽表中可达，不承诺两者同时满载；任何超限都必须明确说明原因，禁止抽样、截断或转云端。M0 必须在真实参考浏览器中验证这些边界与既有三分钟生成目标，若失败须在 M1 前下调公开上限。该约束降低极端稠密表的覆盖，但避免把浏览器无法兑现的理论尺寸写成产品承诺，并补充 ADR-0020。
