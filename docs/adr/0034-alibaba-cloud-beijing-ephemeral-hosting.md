# 官方实例使用阿里云北京的临时内容架构

官方 DataPulse 实例部署在阿里云中国大陆北京地域，创作端与观看端静态资源使用 OSS 和 CDN，预设模型供应商代理、发布、撤销与过期处理使用函数计算及 API 网关，端到端加密的发布快照存入独立 OSS Bucket，并通过不超过 24 小时的生命周期规则与定时清理双重删除；CDN 不长期缓存快照。平台不建设账号、项目或用户内容数据库，只按 ADR-0046 使用强制 TTL 的临时运行状态，并按 ADR-0041 处理获准匿名遥测。该选择绑定阿里云境内基础设施并要求完成域名备案、日志脱敏和生命周期验证，但与中国大陆首发、百炼北京预设、免账户和临时分享模型保持一致，所有部署配置均以基础设施即代码公开。
