# MVP 按可独立验收的纵向切片交付

DataPulse AI 将 MVP 分为五个连续里程碑：M0 建立 monorepo、故事 Schema、合成夹具、CI、迁移、本地加密存储和部署底座；M1 打通导入、字段角色、质量检查、本地分析、基础生成、版本与时间范围编辑；M2 加入证据包和三类模型连接的 AI 增强；M3 完成首批区块、四个主题、品牌、渐进式 3D、端到端加密分享、观看交互和静态导出；M4 完成兼容性、迁移、性能、视觉、无障碍、安全、社区自部署参考配置与冒烟验证，并通过 ADR-0052 的本地自动化闭环语料库后发布公开 MVP。每个里程碑必须形成可运行、可测试的端到端切片并通过本阶段质量门槛，以较晚获得完整功能面为代价，提前验证最关键的数据—故事—编辑—分享链路并降低最终集成风险。
