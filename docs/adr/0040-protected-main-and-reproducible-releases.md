# 采用受保护主干与可复现发布治理

DataPulse AI 采用始终可发布的受保护 `main` 分支，所有修改通过短期分支或 Fork PR 合入并通过强制质量门槛；外部贡献由至少一名维护者批准，普通维护者 PR 可在检查通过后自合并，加密、分享、隐私、Schema 与迁移路径由 `CODEOWNERS` 标记，并在具备两名维护者后强制非作者复核。项目使用 squash merge、Conventional Commit 格式的 PR 标题和面向用户变更的 Changeset，由 GitHub Actions 根据 SemVer 标签生成 Release、变更日志、校验和与 SBOM，禁止从个人设备手工上传正式构建；紧急流程只能绕过等待期或非质量性人工流程，绝不能绕过 ADR-0037 的强制质量门槛，并且必须公开说明和补交复盘。该治理保留早期维护效率，同时使公开仓库的贡献历史、敏感修改和正式产物可审查、可复现。
