# 发布快照在浏览器加密，DataPulse 云端只保存密文

项目所有者浏览器使用随机分享密钥对故事蓝图、交互数据包和选定明细进行认证加密后才上传；无密码分享可将分享密钥置于 URL Fragment，带密码分享则必须按 ADR-0047 只携带由密码派生密钥包裹后的分享密钥，Fragment 不会随 HTTP 请求或日志发送给 DataPulse。观看者下载密文并在本地解密和交互。DataPulse 只保存密文与 ADR-0046 允许的限时运行元数据，因而无法搜索、生成内容预览或检查发布内容，并仍可观察访问 IP、时间和密文大小等传输元数据；该取舍以服务器端内容能力为代价，强化了本地优先和 24 小时临时分享的隐私边界。
