# 发布最小聚合交互数据包

发布快照时，本地分析引擎只为已发布指标、图表和开放分析条件生成必要粒度的维度与版本化精确累加器，并将项目所有者明确选择的明细值以及洞察所需的叙事规则加入受控发布容器；观看者浏览器使用与创作端相同的 codec 和纯指标运行时执行有界解码、筛选、重新聚合及确定性文案更新，不调用模型，无法继续成立的结论必须隐藏或标记不适用，云端也不接收原始表。只有交互 entry 可使用固定单 member gzip，压缩后不得超过 5 MB，且协议还必须固定解码上限并拒绝压缩炸弹。`COUNT_DISTINCT` 只能通过不含原值的发布局部 token 集合并集精确重算，不能相加分组去重数或改用近似值；若精确状态的披露风险不可接受或使包体超限，必须显式关闭受影响筛选／指标交互、降低时间粒度、移除高基数筛选或合并长尾分类，不得静默抽样、预计算指数级组合或回退上传原始表。该选择可能限制高基数维度和任意下钻，但使观看者交互、数值正确性、原始数据本地驻留与 24 小时临时分享能够同时成立，并要求发布前向所有者展示容器内容、编码、能力与大小。
