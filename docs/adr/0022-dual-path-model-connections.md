# 预设模型供应商走无状态代理，自定义端点由浏览器直连

项目所有者自行提供并承担模型调用费用，MVP 的预设模型供应商为阿里云百炼（北京）与 Glosc AI，二者通过无状态代理调用，代理不得记录或保存密钥；任意自定义 Base URL 只能由独立低权限连接器 Origin 在浏览器中直接请求，创作端只通过严格消息协议传递当前请求材料，连接器不能访问项目存储或设备密钥。连接器的每个版本化安全纪元使用从未承载其他应用的独占可注册域，避免其 `Clear-Site-Data: "cookies"` 清理波及创作端、观看端、API 或其他站点；DataPulse 页面与 API 不使用 Cookie，托管基础设施不可避免的 Cookie 必须全部使用 `__Host-` 前缀并满足 `Secure; Path=/`、无 `Domain`。不能提供独占可注册域的自托管部署必须禁用自定义连接器，不能只移除 Cookie 清理后在共享可注册域继续运行。自定义端点必须兼容 OpenAI Chat Completions 请求格式并支持 CORS，公网地址仅允许 HTTPS 且禁止重定向，本机模型可使用 localhost。预设模型供应商只允许从模型目录选择，不接受手填模型 ID：百炼使用 DataPulse 依据北京地域官方资料维护的版本化目录，Glosc 使用鉴权后的 `/models` 结果；所选模型仍须通过连接测试。模型凭据默认只驻留会话内存、明确选择后才设备绑定加密持久化；模型配置在保存前必须通过不含真实数据的合成请求，验证连接、鉴权、模型、简体中文和故事蓝图 JSON 输出。配置页展示当前实际服务条款与隐私政策链接及留存、训练、上游、地域、删除的已核实／待确认项，首次真实证据包调用前确认，披露版本或链接变化后重新确认，记录仅本地保存。每次 AI 增强默认一次调用，只允许因结构校验失败自动执行一次修复调用，网络或供应商错误必须由用户确认后重试；DataPulse 的 24 小时删除承诺不约束第三方供应商或中转站。该决定取代 ADR-0016 的统一代理路径，以部分端点无法跨域调用、用户必须自行信任第三方、多 Origin 与额外可注册域部署且自定义端点只能使用单一协议为代价，支持多供应商订阅与本地模型，同时避免 DataPulse 后端成为 SSRF 或任意流量转发器；自定义端点的模型发现要求由 ADR-0045 补充，供应商协议事实、预设参数和待实测项见 [模型供应商 API 兼容性核验](../research/model-provider-api-compatibility.md)。
