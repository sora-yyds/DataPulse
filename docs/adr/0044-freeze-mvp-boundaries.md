# 冻结 MVP 边界并要求新增范围等量替换

DataPulse AI MVP 明确不包含实时或定时数据源、多表与数据仓库建模、账号和多人协作、永久分享、任意代码与自由画布、预测与因果推断、未列入首批的专业图表和 3D 数据编码、PPTX／视频／GIF／可编辑设计导出、手机或原生应用创作、英文与多地区部署、企业私有化交付、云端原始数据分析、平台公共 AI 额度、自定义端点代理及手填模型 ID。上述能力是延期项而非永久禁止；MVP 期间任何新增需求必须替换同等工作量的既有范围，不允许在不调整里程碑的情况下单纯追加。该约束牺牲横向功能覆盖，以保护“十分钟内生成可编辑、可分享数据故事”这一尚待验证产品目标所依赖的核心工作流。
