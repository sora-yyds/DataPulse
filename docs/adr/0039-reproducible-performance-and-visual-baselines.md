# 性能与视觉回归使用固定可复现基线

DataPulse AI 使用小型、符合 ADR-0011 全部条件的常见档、二十万行窄表行上限型和 50 MB／100 列较短宽表体积上限型合成数据夹具，在固定浏览器、视口、字体、语言、时区及 ADR-0050 的参考硬件档位下执行性能与视觉回归；生成和交互继续遵守既有绝对时延预算，相对主分支的多次运行中位数退化超过 15% 时阻止合并。视觉矩阵覆盖四个主题、主要故事区块、桌面／平板／手机断点及二维降级状态，截图固定随机种子并关闭动效；除受控抗锯齿容差外，所有差异都必须在同一 PR 中经人工审查后显式更新基线，禁止用批量重录掩盖回归。该方案增加 CI 时间与基线维护成本，但使高设计密度界面和浏览器内分析性能具备可审计的发布标准。
